# defect even though it would run. The codes appearing in THIS file are inert comments in a

# a step that needs one imports it from `cpt_acdf`.

#   PRPT       exists 2012-2020 but is 99.06% NULL in this cohort and populated in

#   HDISDT     the name looks like a discharge date; the values are a four-digit

# --- Outcome: mortality, length of stay, disposition --------------------------
# There is NO `DEATH` column anywhere in the warehouse. 30-day mortality must be
# derived from DOPERTOD (days operation -> death, range 0-30) and/or YRDEATH.
# DOPTODIS is TRUE POSTOPERATIVE length of stay (days operation -> discharge) and
# is the analysis length-of-stay variable everywhere in this project. TOTHLOS is
# TOTAL stay and includes the HTOODAY preoperative days; TOTHLOS - HTOODAY is the
# independent cross-check on DOPTODIS and never the analysis variable.
#
# INOUT  THE ONE COLUMN THIS FILE ADDS TO THE PARENT'S LIST. Read all three points
#        before touching it:
#        (a) INOUT is the NSQIP inpatient/outpatient BILLING label, not a discharge
#            measure. Two levels, 'Inpatient' and 'Outpatient', 0% NULL in this
#            cohort (one SQL NULL row exists database-wide, outside 2012-2024 ACDF).
#            It records how the case was booked, not how long the patient stayed.
#        (b) It is DELIBERATELY BANNED in the parent project. `projects/ACDF-hematoma/`
#            omits it from vars/acdf_hematoma.txt and hard-bans it in that project's
#            01_export_cohort.py preflight, because framing rule 3 of that project's
#            v1/CLAUDE.md ("true postoperative length of stay only; never the INOUT
#            billing label") keeps it out of that manuscript entirely. That ban is
#            still in force there and this file does not change it.
#        (c) It is exported HERE because the measurement critique in PLAN.md section
#            6.4 is one of this paper's two headline findings and cannot be done
#            without it: the whole point is to cross-tabulate the billing label
#            against true postoperative length of stay, quantify the disagreement
#            year by year, and re-estimate a published outpatient-versus-inpatient
#            comparison both ways. Removing INOUT from this list silently deletes
#            that finding, which is why 01_export_cohort.py asserts it is PRESENT.
